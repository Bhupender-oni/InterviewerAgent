# GitHub Setup

## Quick Start (3 Commands)

```bash
git init
git add .
git commit -m "Initial commit: AI Interview Agent"
git remote add origin https://github.com/YOUR-USERNAME/interview-agent.git
git push -u origin main
```

Visit: `https://github.com/YOUR-USERNAME/interview-agent`

## .gitignore Protects

- `.env` files with real values
- `__pycache__/`, `venv/`, `*.pyc`
- API keys & credentials
- IDE settings (`.vscode/`, `.idea/`)
- OS files (`Thumbs.db`, `.DS_Store`)
